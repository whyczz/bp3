# Yolo mode: full fan-out, agent decider, budget as the only brake

## Context

Frozen 2026-11-18. Owner, verbatim: "a yolo mode, where we do
have all these subagents, etc."

How autonomy works today:

- `bp3g` (`skills/bp3g/SKILL.md`) conducts one graph, one
  step per read.
- `bp3g-no-human` runs a fleet queue unattended but "never
  attests, never pages, never promotes" and parks blocked
  work in the inbox.
- These are human gates in the engine: `BP3_DECIDER=human` for
  resume, for deleting a blocked node, and for acting on a
  blocked node (`src/graph/main.ml:154,254,423`;
  `store.ml:63`). `max_cycles: 1` escalates a second
  `fix_first` to the human. Owner promotion at landing.

Counter-pressure: the mini-warden context reports the weekly
Muse Max allowance burned in two days, with one author node
at 35 min. Yolo multiplies spend.

## Sketch

A conductor rail, like `bp3g-no-human` (a skill mode, no new
FSM), plus one engine change.

```text
            ┌─ node a ─ author ─ grade ─ land ─────────┐
graph ──────┼─ node b ─ author ─ grade ─ fix ─ grade ──┼─> graph landed on bp3/graph/<slug>
frontier    └─ node c ─ blocked ─ agent decider ─ ...  ┘     └─> human: Landing IIUC, promote?
```

- **Frontier fan-out:** dispatch every node whose deps have
  landed, concurrently, up to cap N, one desk (worktree) each.
- **Agent decider:** new `BP3_DECIDER=agent`. An agent may
  resume or route a blocked node. Every such cast is ledgered
  `decider: agent` with its reason, so the human can audit and
  revert.
- **More cycles:** `max_cycles` is raised under yolo; a second
  `fix_first` goes to the agent decider, not a page.
- **Budget is mandatory:** yolo with no stated token or
  wall-time budget is refused, and the budget is the only brake.
- **Never:** promote to `master`, push, force-update, or delete
  graphs. The Landing IIUC is still owed to a human.

## Blockers

- **The definition is the first decision.** Which human gates
  does yolo remove (resume, delete-blocked, fix_first
  escalation, attest), and is promote truly fixed? The owner
  lists them.
- **Mid-flight budget enforcement needs metrics** that don't
  exist yet ([2026-11-18-metric-collectors.md](2026-11-18-metric-collectors.md)).
- **Self-review:** the agent decider judging its own fleet.
  Grading on a different model
  ([2026-11-15-grade-model-routing.md](2026-11-15-grade-model-routing.md))
  likely becomes a prerequisite.
- **Parallel nodes on one graph branch:** fleet merge order
  exists for graphs, not for sibling nodes inside one graph.
- **Engine caps:** Muse workflows allow 16 concurrent children
  (`docs/dossiers/muse-workflows-hooks.md`). pi and Claude Code
  are unmeasured ([2026-11-18-claude-code-engine.md](2026-11-18-claude-code-engine.md)).
- **Spend:** mini-warden budgets should land first, or yolo
  burns the week faster.

## Promotion trigger

Thaw when a `bp3g-no-human` check-in report shows that most
parked items were mechanical decisions an agent could have made,
and the mini-warden budgets are being met.
